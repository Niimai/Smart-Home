# Descripción y Alcance

Smart Home es una aplicación académica desarrollada en Python y SQLite.

## Objetivo

Gestionar habitaciones y dispositivos inteligentes.

## Alcance

La aplicación permite:

- Crear habitaciones
- Agregar sensores
- Agregar actuadores
- Activar y desactivar actuadores
- Consultar dispositivos

No incluye interfaz gráfica ni red.
