# Casos de Uso

## Agregar habitación
Permite crear una nueva habitación.

## Agregar sensor
Permite agregar sensores a una habitación.

## Agregar actuador
Permite agregar actuadores a una habitación.

## Activar actuador
Permite activar un actuador.

## Desactivar actuador
Permite desactivar un actuador.

## Listar habitaciones
Muestra todas las habitaciones.

## Listar dispositivos
Muestra dispositivos de una habitación.
