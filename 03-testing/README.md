# Smart Home

Proyecto académico desarrollado en Python siguiendo principios de Clean Architecture.

## Características

- Gestión de habitaciones
- Gestión de sensores
- Gestión de actuadores
- Arquitectura por capas
- Persistencia en memoria
- Menú CLI
- Tests unitarios
- Cobertura con coverage

## Estructura

- domain/
- application/
- docs/
- infrastructure/
- interfaces/
- tests/

## Ejecución

```bash
python main.py
```
